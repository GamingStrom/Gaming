# NEXUS Complete Website

A premium static gaming marketplace frontend.

## Included
- Marketplace homepage
- Product search and category filters
- Product purchase modal (demo)
- Login and registration UI
- Creator dashboard UI
- Publisher listing form
- Server section
- Privacy, Terms and Support pages
- Responsive mobile layout

## Run
Open `index.html` in a browser or Acode.

## Production requirements
This package is still a frontend/demo. Real authentication, payments, order processing, secure file storage, publisher verification, downloads, email and database features require a backend/service such as Firebase or another suitable provider.
